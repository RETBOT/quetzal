# Registro de skills RETBOT v2.1

El registro es documentación, no una skill cargable. Las skills nuevas viven en `skills/<name>/SKILL.md` y pueden distribuirse por Agent Plugins.

| Skill | Agente | Cobertura |
|---|---|---|
| `engineering-flow` | Quetzal | Flujo proporcional de exploración, implementación, verificación y revisión. Reemplaza el SDD antiguo como ruta activa. |
| `dotnet-efcore` | Quetzal | EF Core, LINQ, SQL Server, migraciones, tracking y rendimiento. |
| `dotnet-maui` | Quetzal | Android, iOS, Windows, navegación, DI, ciclo de vida y UI multiplataforma. |
| `dotnet-windows-forms` | Quetzal | `.csproj`, clases, Designer, RESX, referencias, inclusión y compilación. |
| `aspnet-mvc` | Quetzal | ASP.NET MVC, Razor, controllers, routing y request security. |
| `react-frontend` | Quetzal | React, componentes, hooks, estado y rendering. |
| `devextreme` | Quetzal | DataGrid, CustomStore, virtual scrolling, DataSourceLoader y componentes. |
| `javascript-web` | Quetzal | JavaScript, jQuery, AJAX, DOM y async. |
| `api-design` | Quetzal | REST, contratos, versionado, errores, idempotencia y resiliencia. |
| `network-analysis` | Kukulkán | Redes, protocolos y tráfico. |
| `web-api-pentest` | Kukulkán | Pentesting web/API autorizado y OWASP. |
| `vulnerability-triage` | Kukulkán | CVE/CWE/CVSS, impacto y mitigación. |
| `llm-security` | Kukulkán | Prompt injection, RAG, agentes y MCP. |
| `security-lab-design` | Kukulkán | Laboratorios aislados, reproducibilidad y limpieza. |

Las cuatro skills existentes `code-review`, `refactoring`, `testing` se conservan. La skill `sdd` se retira de la ruta activa cuando sus comandos/dependencias se migren; consulta `LEGACY-SDD-RETIREMENT.md`.
